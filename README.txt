Student Progress Tracker Pro is a Python coursework project for IY499. It manages student records, attendance, modules, assessments, and overall progress. The project includes three versions of the same system: a console program, a Tkinter desktop application, and a Flask web application. All three versions share one backend file, which improves code reuse and organisation.

The project demonstrates file handling by saving data to JSON, exporting reports to CSV, and writing activity logs. It includes error handling through validation and custom exceptions, plus an explicit linear search algorithm and an explicit bubble sort algorithm for stronger code coverage. The Tkinter version also provides data visualisation using a Canvas bar chart that displays student average scores.

To run the project, install the required packages with pip install -r requirements.txt. Then run python console_app.py, python tkinter_app.py, or python flask_app.py. Testing can be checked with python tests.py. References for libraries, documentation, and features are included in code comments and in README.md.
